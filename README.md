# CyberPress Fast

Professional WordPress theme template for an **English cybersecurity news** website.

## Theme folder

`cyberpress-security-news-theme`

## Features

- Professional dark cybersecurity style.
- Homepage hero section for cyber news branding.
- Card-based latest posts layout.
- Single and archive templates.
- Footer social icons (X, LinkedIn, YouTube, GitHub, Telegram).
- Social links editable from **Appearance → Customize → Social Links (Footer)**.

## Installation

1. Copy `cyberpress-security-news-theme` to:
   `wp-content/themes/`
2. In WordPress admin, go to **Appearance → Themes**.
3. Activate **CyberPress Security News**.
4. Optionally create and assign a menu to **Primary Menu**.
5. Set social URLs in the customizer section.
